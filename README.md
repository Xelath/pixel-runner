# 像素跳跃 · Pixel Runner

一款单文件 Canvas 2D 像素风格平台跳跃游戏，支持多人联机。

## ✨ 功能特性

- 🎮 **32 个关卡**，分两个篇章，含 Boss 战
- 👾 **8 种普通怪物 + 3 个 Boss**，各有独特行为
- 📖 **怪物图鉴**：收录所有敌人与 Boss 的信息
- 🛒 **能力商店**：用通关金币购买永久能力（磁铁 / 护盾 / 冲刺 / 跳跃）
- 🎁 **每关临时道具**：护盾 / 减速 / 磁铁 / 超级跳
- 💎 宝石收集、奖章系统、每日挑战、无尽模式
- 🌐 **多人联机**：通过 WebSocket 房间实现合作闯关
- 🎨 8 款角色配色（收集宝石解锁）
- 📱 触屏支持，自动显示虚拟按键

## 🛠 技术栈

- 纯 **Canvas 2D** 渲染，无游戏引擎
- **JavaScript**（ES6+），源码按功能拆分
- **Node.js** 构建脚本（`build.js` 拼接单文件）
- **ws** 实现多人联机中继服务器

## 🚀 快速开始

### 直接玩

打开根目录的 `index.html` 即可开始游戏（无需服务器）。

### 本地开发 / 联机

```powershell
# 安装依赖（联机服务器需要）
npm install

# 启动联机服务器（同时托管静态页面）
npm start
```

然后浏览器访问 `http://localhost:你的端口`。

### 从源码构建

源码在 `src/` 目录，修改后需要重新构建：

```powershell
npm run build
# 或
node build.js
```

构建会生成单文件 `index.html`。

## 🎯 操作说明

| 按键 | 功能 |
|---|---|
| A / D 或 ← / → | 左右移动 |
| S | 下蹲（配合跳跃下穿单向平台） |
| 空格 | 跳跃（空中再按 = 二段跳，长按跳更高） |
| Shift | 冲刺（短暂无敌，1.5 秒冷却） |
| ESC | 暂停 |
| R | 重试本关 |
| M | 静音 |
| F | 全屏 |

触屏设备自动显示虚拟按键：左下方向，右下跳跃 / 冲刺。

## 📁 项目结构

```
.
├── index.html              # 构建产物（直接打开即玩）
├── build.js                # 构建脚本：把 src/ 拼接成单文件
├── package.json            # 依赖与脚本
├── server.js               # 多人联机 WebSocket 服务器
└── src/                    # 源码（按功能拆分）
    ├── 01-config.js        # 基础配置、物理参数、关卡数据
    ├── 02-levels.js        # 关卡定义
    ├── 03-core.js          # 存档、音效、粒子、UI 布局
    ├── 04-input.js         # 输入处理（键盘 / 触屏 / 手柄）
    ├── 05-level.js         # 关卡运行时（平台、敌人、陷阱）
    ├── 06-world.js         # 世界与相机
    ├── 07-game.js          # 游戏状态机、玩法逻辑
    ├── 08-net.js           # 多人联机同步
    ├── 09-render.js        # 所有渲染逻辑
    ├── 10-main.js          # 启动入口
    └── index.template.html # HTML 模板
```

## 📝 开发约定

- 修改源码请改 `src/` 内的分块，**不要直接改 `index.html`**（会被构建覆盖）
- 构建后用 `node -e` 做语法检查，确保没有拼接错误
